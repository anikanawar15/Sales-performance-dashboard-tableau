# Sales Performance Dashboard | Tableau

## Project Overview

An interactive Sales Performance Dashboard developed using **Tableau** to explore sales performance, profitability, product trends, geographical distribution, and customer behavior.

The project focuses on transforming transactional sales data into clear, actionable visualizations that support business decision-making.

## Key Features

### 1. Geographic Sales Analysis
- Visualizes sales performance across US states.
- Uses bubble size to represent sales volume.
- Uses color to represent profitability.
- Helps identify high-performing and loss-making geographical markets.

### 2. Product Performance Analysis
- Compares sales and profit across product subcategories.
- Uses a scatter plot to visualize the relationship between revenue and profitability.
- Highlights products with strong sales but low or negative profits.

### 3. Sales and Profit Trend
- Visualizes monthly sales using vertical bars.
- Displays monthly profit using a line chart.
- Uses a dual-axis approach to compare trends over time.
- Supports the identification of fluctuations and potential seasonal patterns.

### 4. Customer Performance Analysis
- Measures the number of unique customers.
- Calculates average sales per customer.
- Compares customer activity across quarters.
- Supports quarter-over-quarter customer growth analysis.

## Dashboard Interactivity

The dashboard is designed to support interactive exploration through filters, tooltips, and connected views, enabling users to examine performance across different business dimensions.

## Business Applications

The dashboard can help stakeholders:

- Identify profitable and underperforming markets.
- Evaluate product-level revenue and profitability.
- Monitor changes in sales and profit over time.
- Understand customer purchasing patterns.
- Make data-informed business decisions.
